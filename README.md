# Take Home Pay Calculator UK

Free UK take-home pay calculator — enter gross salary, region and (optionally)
pension contribution and student loan plan to get instant Income Tax,
National Insurance, student loan and pension deductions. England, Scotland,
Wales, Northern Ireland. 2026/27 rates.

**Live site:** [mynetsalary.co.uk](https://mynetsalary.co.uk) (domain pending
availability check + DNS setup)

## Features

- Universal calculator (England/Wales/NI vs Scotland income tax bands) — homepage
- 8 satellites: PAYE, National Insurance, dividend tax, self-employed tax,
  student loan repayment, redundancy pay, maternity pay, pension contribution
- Every page links back to the pillar calculator and out to all satellites
  (bidirectional `.sat-grid`)
- 3 CTA snippet families, mapped by topic cluster (not one generic CTA):
  accountancy (self-employed/dividend), IFA/financial-advice (pension/
  redundancy/maternity/student-loan — the cluster's two highest-CPC
  satellites), payroll-software (pillar/PAYE/NI)
- JSON-LD: WebApplication + FAQPage + HowTo + BreadcrumbList + Organization
  (kept for markup correctness / AI-crawler citability — HowTo/FAQ rich
  results are being retired by Google, not relied on for SERP display)
- `sitemap.xml` auto-generated by `generate-pages.js`

## Build

```bash
node generate-pages.js   # emits all 8 satellite folders + sitemap.xml
```

The homepage `index.html` is hand-written; everything else is generated.
Income Tax/NI/student-loan constants in `generate-pages.js` must be kept in
sync with the `<script>` block in `index.html` if rates change.

## Deploy

Push to `main` → GitHub Pages workflow (`.github/workflows/pages.yml`)
publishes the repo root. Custom domain via `CNAME` (`mynetsalary.co.uk`) —
verify domain availability and point DNS (A records to GitHub Pages IPs, or
CNAME to `<username>.github.io`) before traffic will resolve.

rationale):

1. **Online accountant / limited-company-formation affiliate** — self-employed
   tax calculator and dividend tax calculator (real ad competition 0.27 and
   £0.97 CPC signal genuine advertiser demand). **Replace placeholder `href="#"`
   links before going live**, and verify actual commission terms before
   publishing numbers in copy.
2. **IFA/financial-advice comparison affiliate** — pension contribution,
   redundancy pay, maternity pay, and student loan repayment calculators
   (all four are lump-sum/family-financial decision moments; maternity and
   student-loan carry this cluster's two highest CPCs, £0.92 and £1.00).
3. **Payroll software affiliate** (Xero/QuickBooks/BrightPay) — pillar, PAYE
   calculator, National Insurance calculator only.
4. Display ads once traffic is stable — independent layer given the
   cluster's 600k+/mo combined pillar+alias volume.

## Data sources & disclaimer

Rates are **guidance** compiled from HMRC, Revenue Scotland/gov.scot, and DWP
published 2026/27 figures, applied deterministically — **not** tax or legal
advice. The Statutory Sick Pay day-1/no-LEL reform (Employment Rights Act
2025, in force 6 April 2026) was cross-checked directly against
gov.uk/statutory-sick-pay before publishing. Other figures (redundancy cap,
statutory parental pay rate) were sourced from payroll-industry secondary
sites — cross-check against gov.uk before relying on them for a real
decision. Always confirm your own position via
[gov.uk/estimate-income-tax](https://www.gov.uk/estimate-income-tax) or a
qualified adviser.
